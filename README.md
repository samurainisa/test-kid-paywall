# TestKidTask

Мобильный экран покупки доступа к детской игре на **Nuxt 4 и TypeScript**. Можно выбрать тариф на месяц или год, купить доступ и восстановить покупку. Покупка тестовая — деньги не списываются.

[Приложение](https://test-kid-paywall-production.up.railway.app) · [Figma](https://www.figma.com/design/7VigLCRaHdb6H4SG1h8VnM/TestKidTask) · [GitHub](https://github.com/samurainisa/test-kid-paywall)

## Запуск

Нужен **Node.js 22.23.1**. В папке проекта выполните:

```sh
npm ci
npm run dev
```

Откройте `http://localhost:3000`. Для запуска собранной версии:

```sh
npm run build
npm start
```

## Структура проекта

- `app/` — экран покупки, компоненты и страница «Игра открыта».
- `server/api/` — запросы для загрузки тарифов, покупки и восстановления.
- `server/utils/db.ts` — подключение SQLite и создание таблицы.
- `server/utils/purchases.ts` — сохранение и поиск покупок.

## Размещение и база данных

Приложение размещено на **Railway**. Frontend и сервер работают в одном Nuxt-проекте. Сборка и запуск настроены в Dockerfile.

Используется **SQLite**: для небольшого учебного сервиса достаточно одного файла без отдельного сервера БД. Покупка хранит тариф, дату и идентификатор устройства.

Локально база создаётся автоматически в `data/paywall.sqlite`. На Railway для неё нужен постоянный диск `/data` и переменная `SQLITE_PATH=/data/paywall.sqlite`. Сервис работает в одной реплике.

Восстановление доступно в том же браузере, пока сохранена cookie. После её удаления или на другом устройстве покупка не восстановится.

## ИИ и проверки

Использован **Codex** для реализации, тестирования и документации. Экран собран по макету с готовыми изображениями и локальным шрифтом.

Автоматически проверены TypeScript, сборка, серверные запросы, запись и восстановление покупки, защита от повторов, ошибки, пять состояний экрана и мобильные размеры. В опубликованной версии покупка сохранилась после двух повторных деплоев Railway.

Для повторения локальных проверок:

```sh
npm run typecheck
npx playwright install chromium
npm test
```
