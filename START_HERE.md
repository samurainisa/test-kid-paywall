# Как передать пакет агенту

Распакуй архив в рабочую папку агента. Отправь следующий текст:

Прочитай IMPLEMENTATION_PROMPT.md полностью и изучи assets/ и reference/. Реализуй тестовое задание в одном проекте Nuxt 4 + TypeScript с SQLite. Вёрстку делай по пяти эталонным изображениям и точным измерениям, используй готовые локальные SVG и шрифт. Выполни рабочий серверный сценарий, запись и восстановление из БД, адаптацию и визуальные проверки. Затем подготовь размещение с постоянным диском, короткий README и отчёт о реально проведённых проверках. Не останавливайся после плана. Если для публикации отсутствует доступ к платформе, закончи всё независимое и укажи конкретный оставшийся шаг.

Исходный файл source/TestKidTask.fig можно импортировать в Figma. Он не заменяет измерения и экспортированные изображения.

reference/*.tsx — справочное описание, не код для прямого переноса: используется другой стек и упрощённая логика вариантов карточек. Реализация должна следовать IMPLEMENTATION_PROMPT.md.
